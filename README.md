## Featured Projects

### 👤 [User Management System](https://github.com/marcelobezerrajr/sistema-gestao-de-usuarios)
Complete web application for managing users securely and efficiently, with access control and customized permissions. The system allows different access levels (Admin, User, and Read) that can register, edit, remove, and manage user permissions at different access levels, according to their permissions.

`FastAPI` `Python` `React` `CSS` `PostgreSQL` `Docker` `Alembic` `Auth` `RBAC` `REST API`

---


### 🏥 [Medical Reports](https://github.com/marcelobezerrajr/laudos-medicos)
Backend developed for managing medical reports, optimizing workflow between doctors and patients. The project integrates CRUD functionalities for users, doctors, patients, exams, and reports. The system also offers support for uploading and managing images related to exams and reports, making it ideal for clinics seeking an efficient and modern solution to monitor their internal processes.

`FastAPI` `Python` `PostgreSQL` `Docker` `REST API`

---

### 🎮 [DSList](https://github.com/marcelobezerrajr/dslist-backend)
RESTful API, developed in Java with Spring Boot,  based on a project by Professor Nélio Alves from DevSuperior. The project's goal is to manage a list of games, allowing users to view, organize, and customize their favorite titles.

`Spring Boot` `Java` `PostgreSQL` `Docker` `Lombok` `REST API`
